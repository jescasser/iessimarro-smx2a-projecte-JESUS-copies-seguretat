# Copies de seguretat — Projecte Intermodular SMX

Una xicoteta gestoria necessita guardar els documents importants dels seus clients per a evitar perdre'ls si s'esborren per error o si l'ordinador deixa de funcionar. Per a solucionar-ho, es faran còpies dels documents en una memòria USB i es comprovarà que es poden obrir correctament.

## Autor

- JESUS (@jescasser)

## Rols simulats

- **Rol A** — Organitzar les tasques i escriure els documents del projecte.
- **Rol B** — Preparar les carpetes i copiar els documents a la memòria USB.
- **Rol C** — Comprovar que les còpies s'han fet bé i que els documents es poden obrir.

## Contingut del repositori

- `documents/` — Document de Repte (Annex A).
- `documents/fitxes/` — Fitxes d'activitat (Annex B).
- `configuracio/` — Configuracions tècniques (quan s'execute el projecte).
